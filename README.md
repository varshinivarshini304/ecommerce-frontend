# Ecommerce Frontend

Responsive E-Commerce Website UI Development starter project.

## Project structure

- `index.html` - main HTML entry
- `styles/main.css` - base styles
- `scripts/app.js` - starter JavaScript
- `assets/` - project images and static assets
- `.gitignore` - files excluded from Git
- `package.json` - npm metadata

## Getting started

1. Open `index.html` in your browser.
2. Edit `styles/main.css` and `scripts/app.js` to build the UI.
